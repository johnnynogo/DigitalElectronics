# DigitalElectronics
02MIVXU Digital Electronics

### VHDL conventions that I have tried to follow:
- Using lowercase VHDL keywords and consistent 4-space indentation.
- Using snake_case for entity, architecture, and file names.
- Using rtl for synthesizable hardware architectures.
- Using end entity name; and end architecture name; for clarity.
- Aligning port declarations and keeping formatting consistent.
- Using descriptive names for reusable components.
- Keeping board-specific top-level entities separate from reusable components.
- Removing unnecessary comments.
- Keeping one primary entity per .vhd file, with a matching filename.
- Using numeric_std for signed and unsigned arithmetic.
- Using named port associations (=>) when instantiating components.
